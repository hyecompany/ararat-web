# Get Endpoint Details

Use the get-endpoint script to retrieve the full documentation for a specific Incus API endpoint, including its parameters, request body schema, and response schemas.

## Usage

```bash
bun run .agents/skills/incus-api-docs/scripts/get-endpoint.ts <method> <path>
```

- **`<method>`**: The HTTP method (GET, POST, PUT, PATCH, DELETE, etc.).
- **`<path>`**: The exact API path (e.g., `/1.0/instances`).

## Example

- **Get details for GET /1.0/instances**:
  `bun run .agents/skills/incus-api-docs/scripts/get-endpoint.ts GET /1.0/instances`

## ⚠️ Critical Warning: Autogenerated Examples

The Incus API specification is autogenerated, which primarily affects the examples shown in endpoint responses. These examples are often **highly generalized** and may not represent the exact structure of the response metadata, especially if no explicit `$ref` schema definition is provided for that response.

**Strict Guideline:**
- Do not trust the literal shape of the example objects provided in the endpoint's `responses` section.
- Instead, look for `$ref` pointers to formal schema definitions and retrieve those definitions using the `get-definition.ts` script to understand the actual data structure.

## When to use
Use this script when you have a specific endpoint path and need to understand what parameters it accepts or what request body it expects.
