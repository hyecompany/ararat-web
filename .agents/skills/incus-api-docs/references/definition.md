# Get Definition Schema

Use the get-definition script to retrieve the formal schema for a specific Incus API type or object definition.

## Usage

```bash
bun run .agents/skills/incus-api-docs/scripts/get-definition.ts <name>
```

- **`<name>`**: The exact name of the definition (e.g., `Instance`, `AccessEntry`).

## Example

- **Get the schema for the Instance object**:
  `bun run .agents/skills/incus-api-docs/scripts/get-definition.ts Instance`

## 💎 The Single Source of Truth

The formal schema definitions are the only way to reliably understand the structure of objects in the Incus API. Unlike the autogenerated examples found in endpoint responses, these definitions provide the precise fields, types, and required properties for the API's internal models.

## When to use
Use this script whenever you encounter a `$ref: "#/definitions/SomeName"` in an endpoint documentation or need to know the exact properties of an Incus API object like `Instance`, `Network`, or `StoragePool`.
