# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Stack

Next.js (App Router, static export), React 19, TypeScript 5, Tailwind CSS v4, shadcn/ui. Package manager: **Bun**.

## Commands

```bash
bun run dev          # Start dev server (proxy on :3001 + Next.js on :3000 concurrently)
bun run lint         # ESLint check
bun run format       # Prettier write (all files)
bun run ci           # lint + build (used in CI)
bun run build        # Next.js static export to out/
bun run build:route-map  # Generate route-map.json (run after build)
bun run build-install    # Full pipeline: build + route-map + deploy (requires sudo)
```

## Dev Proxy

`bun run dev` starts two servers:
- **:3001** — HTTPS dev proxy (the only entry point — use this in the browser)
- **:3000** — Next.js dev server (internal, proxied through :3001 — do not access directly)

The proxy routes all traffic — always use **:3001**, never access :3000 directly:
- Paths starting with `/ui` → Next.js at `http://localhost:3000` (internal only)
- Everything else → Incus API at `https://localhost:8443`

Required files (not in git — copy from Incus host):
- `server.crt` + `server.key` — from `/var/lib/incus/` on the Incus host
- `ararat.pfx` — client certificate for authenticating to the Incus API

Env vars (set in `.env`):
- `DEV_PROXY_UPSTREAM_CLIENT_PFX=1` — enable client certificate auth for the Incus API
- `DEV_PROXY_UPSTREAM_CLIENT_PFX_PATH` — path to PFX file (default: `./ararat.pfx`)
- `DEV_PROXY_UPSTREAM_CLIENT_PFX_PASSPHRASE` — passphrase for the PFX file

## Static Export

This app uses `output: 'export'` with `basePath: '/ui'`. All routes are prefixed with `/ui`. There is no runtime server — no API routes, no server actions that require a running Node process, no `getServerSideProps`. Keep this in mind when adding features.

## Project Structure

Components are organized using the colocation convention: place a new component in the lowest `_(directory)` folder where it is most commonly shared. Each route and parent route has its own `_(directory)` (e.g., `_context/`, `_hooks/`, `_lib/`).

Path aliases:
- `@/*` → project root
- `ui-web/components/*` → `./components/ui/*`
- `ui-web/hooks/*` → `./hooks/*`
- `ui-web/lib/*` → `./lib/*`

## shadcn/ui

`components/ui/` is auto-generated by the shadcn CLI — do not hand-edit files there. To add a component: `bunx shadcn add <component>`.

## Code Style

Prettier config: `singleQuote`, `semi`, `printWidth: 100`, `trailingComma: 'all'`, `tabWidth: 2`, JSX uses double quotes (`jsxSingleQuote: false`). The `prettier-plugin-tailwindcss` plugin auto-sorts Tailwind classes.

## Git Conventions

Branch naming: `feat/`, `bugfix/`, `chore/` prefixes.

**Never commit** `.env`, `*.crt`, `*.key`, or `*.pfx` files.
