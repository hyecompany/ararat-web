# Contributing to Hye Ararat

Thank you for your interest in contributing to Hye Ararat!

## Reporting Issues
If you find a bug or have a feature request, please open an issue using the provided GitHub issue templates. Make sure to search existing issues before creating a new one.

## Submitting Pull Requests
1. Fork the repository and create your feature branch.
2. Commit your changes and ensure they are signed-off (see DCO below).
3. Push your branch to your fork and submit a Pull Request.

## Developer Certificate of Origin (DCO 1.1)
To ensure that all contributions are properly licensed, we require that all commits be signed off under the Developer Certificate of Origin 1.1.

You can sign off your commits by using the `-s` or `--signoff` flag with `git commit`:
`git commit -s -m "Your commit message"`

This adds the following line to your commit message:
`Signed-off-by: Your Name <your.email@example.com>`
